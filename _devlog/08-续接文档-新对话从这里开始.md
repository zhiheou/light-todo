## 〇之三、v3.9.4 踩的坑（血泪，别再犯）

1. **Electron 打包依赖下载失败**：GitHub 连不上。必须设
   `export ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/`
   **光设镜像不够** —— app-builder 解包后 `rename` 跨盘会失败，需手动把解包内容放到
   `Cache/nsis/nsis-3.0.4.1/` 和 `Cache/nsis/nsis-resources-3.4.1/`；
   再加 `-c.win.signAndEditExecutable=false` 绕开 winCodeSign（那个组件创建符号链接需要管理员权限）。
   **完整可用命令**：
   ```bash
   cd desktop && CSC_IDENTITY_AUTO_DISCOVERY=false \
     ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/ \
     npx electron-builder --win -c.win.signAndEditExecutable=false
   ```
2. **preload 里别删 `ipcRenderer`**：它被 `petAPI` 的每个方法用着，删了会整页被 ErrorBoundary 接住、桌宠完全不显示。
3. **`webContents.send` + `ipcRenderer.on` 在这套配置下收不到**：屏幕参数改用主进程 `executeJavaScript` 直接写 `window.petDisplay`。
4. **contextBridge 的 getter 会被求值一次就冻结**，不能做动态转发。
5. **`filter-branch` 会删工作区文件**：改写历史前先备份。
6. **多会话并行**：用户可能同时开多个对话改同一个项目 → 接手前 `git log -3` 确认。
