## 二、这一轮（v3.9.15~v3.9.20）做了什么

### 1. 修了"改了没反应"的总根源之一：**版本号从没提过**
`desktop/package.json` 的 `version` 一直是 `3.9.4`，而代码做到 v3.9.20
→ 远端 latest.yml = 本地 = 3.9.4 → **自动更新永远不触发**。
**修**：提到 3.9.20；`release.sh` 加版本一致性校验（不一致就中止发布）。

### 2. 修了"改了没反应"的总根源之二：**页面缓存**
Electron 把线上页面缓存到本地，用户程序里跑的可能是**几轮前的旧版**。
**修**：URL 加 `_v=<启动时间戳>`（`withCacheBuster`）。
⚠️ **不要用 `session.clearCache()`** —— 实测会导致窗口建不出来。

### 3. 修了 **5 次同类事故**：浮层漏登记 → 点了没反应、穿到桌面
桌面版桌宠窗铺满整屏 + 鼠标穿透 → **任何能点的东西都必须登记为可点击区域**。
| # | 漏登记的浮层 | 用户报的现象 |
|---|---|---|
| ① | `.pet-menu` 右键菜单 | "右键那么多功能没有一个可以用的" |
| ② | `.pet-summon` 召回按钮 | "隐藏之后召不回来" |
| ③ | `.mascot-panel` 聊天面板 | 一开始就漏 |
| ④ | `.pet-config` 设置面板 | "点皮肤和行为没反应" |
| ⑤ | **`.pet-config-overlay` 全屏蒙层** | 点面板外想关闭 → 穿到桌面 |

**治本**：`startAutoHitAreaScan()`（`src/lib/desktopBridge.ts`）
用 MutationObserver + 定时兜底**自动扫描** `AUTO_LAYER_SELECTORS` 里的所有浮层。
**→ 以后新增浮层，只要加进那个数组即可；`tests/auto-hit-area.test.ts` 会断言清单完整性。**

## 三、🔴 还没解决的问题（新对话优先处理）

### 1. **拖动只跟一半**（用户报过多次，最顽固）
**已查清的根因**（有实测证据）：
```
pointerdown → 12次 pointermove（一路跟随）→ lostpointercapture ← 断在这里
```
鼠标跑到宠物**前面约 280px** 时，判定"鼠标不在宠物上" → 切回穿透 → pointer capture 失效 → 拖拽中断。

**已做的三层保护**（都在代码里，但**未能可靠验证**）：
1. `desktop/main.js`：拖拽期间 `if (mouseHeld) return;`（不切穿透）
2. **系统级鼠标监听**：常驻 PowerShell 读 `GetAsyncKeyState` → `mouseHeld`
3. 页面侧 `setMouseTakeover(true)` 钉住

**⚠️ 我的验证方法本身有问题**：用 PowerShell 模拟鼠标极不稳定（启动延迟、时序对不上），
测出来的结果忽好忽坏。**下次别再用模拟鼠标验证拖动**，改用：
- **让用户实拖**（他说"拖不动"就是真拖不动）
- 诊断按钮已内置：**右键桌宠 → 「🔍 拖不动？点这个」** → 录 10 秒 → 结果自动复制到剪贴板
- **让用户把结果发过来**，里面有主进程状态（是否穿透/是否钉住/是否检测到按住/监听是否在跑）

## 四、关键坑（血泪，别再犯）

### 打包桌面版
```bash
cd desktop
export CSC_IDENTITY_AUTO_DISCOVERY=false
export ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/
npx electron-builder --win -c.win.signAndEditExecutable=false
```
- **必须带 `-c.win.signAndEditExecutable=false`**（绕开 winCodeSign 权限问题），
  图标与版本信息由 `scripts/after-pack.cjs` 钩子补写
- **每次改安装包相关，必须提升 `desktop/package.json` 的 `version`**（否则自动更新失效）
- 打包前自检：`node scripts/smoke-main.mjs && node scripts/check-undefined.mjs`
  （前者会真跑一遍 main.js，能抓"变量被删"这类运行期崩溃）

### 发布到线上下载源
```bash
cd worker
export CLOUDFLARE_API_TOKEN="$(cat ~/.cf-token)"
npx wrangler r2 object put "light-todo-downloads/light-todo-setup-X.Y.Z.exe" --file="..." --remote
npx wrangler r2 object put "light-todo-downloads/latest.yml" --file="..." --remote
```
⚠️ **`--remote` 必须带**（否则传到本地模拟目录）

### 🔴 `wrangler deploy` 会自动"改造"项目
会自作主张装 `@cloudflare/vite-plugin`、改 `vite.config.ts`/`package.json`、新建 `wrangler.jsonc`
→ **`npm test` 直接启动失败**。
**→ 跑完 `wrangler <cmd>` 必须 `git status` 检查有没有被偷改文件。**

### 测试方法（血泪）
1. **UI 问题验收必须用真实鼠标**（PowerShell `mouse_event`），`element.click()` 绕过命中检测
2. **必须连到用户正在运行的程序上测**：`--remote-debugging-port=9333` + CDP（`ws` 模块）
3. 测试脚本的鼠标移动要在**一个 PowerShell 进程内**完成（每步起一个进程有几秒延迟）
4. 涉及"能不能点"的改动 → 用 `pet-debug-state` IPC 读主进程状态，**别猜**

### 其他
- `setMouseTakeover(false)` 这类**成对操作的释放动作，一律放函数最前面**（曾写在提前 return 后 → 永久锁死）
- `sessionStorage` **不跨窗口共享** → 会话必须存 `localStorage` + TTL
- `getCursorScreenPoint()` 返回的**就是 DIP**（Electron 官方文档），**不要再除 scaleFactor**
- 每修一个 bug：**加测试** + 登记进 `_devlog/07-问题解决知识库.md`
