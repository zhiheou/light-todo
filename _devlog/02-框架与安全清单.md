# 框架地图 ｜ 轻待办（Light Todo）

> 面向小白的「整体框架 + 安全 + 运维」常驻说明书。改代码时同步维护。

## 一、这个应用是怎么长成这样的（30 秒版）

```
浏览器(你点开 https://todo.aebuiyke.xyz)
   │  ① 打开页面 = 下载"前端程序"(React 写好的界面)
   ▼
前端程序（src/ 目录，运行在你浏览器里）
   │  ② 你要"注册/登录" 或 "保存任务" 时 → 发请求给"后端"
   ▼
Cloudflare Worker（worker/ 目录，运行在云上，全球都有节点）
   │  ③ 后端只负责：认账(登录) + 帮你把"加过密的盒子"存起来/取出来
   ▼
D1 数据库（相当于云上的 SQLite 文件，Worker 专属）
```

**重点**：你的任务内容是**加密成一团乱码**才存到 D1 的（密钥由你的密码生成），
所以就算有人偷到数据库也读不懂。**密码=密钥，忘了=数据永远找不回**（不是 bug，是安全特性）。

### 前端内部（代码怎么分块）
- `App.tsx` — 大总管：所有数据、所有"现在选了什么页面"的状态都在这，负责存取与接线
- `components/` — 界面零件（侧栏/今日页/日历/目标/备忘录/任务卡片…都各自一个文件）
- `lib/` — 工具函数（不含界面）：日期解析、循环规则、加解密、NLP、吉祥物逻辑
- `v3.5+ 吉祥物相关`：`MascotAvatar/MascotAssistant/PetShell/BloubAvatar`（界面）+ `lib/mascotBrain`（会想什么/说什么）+ `lib/bloub`（身体变形的引擎，照搬开源 MIT）
- 界面上能点的几乎都在 `components`，改界面找那里；数据规则几乎都在 `lib`，改逻辑找那里

### 后端内部（`worker/`）
- `src/index.js` — 单文件：所有 API 入口（登录/注册/同步/聊天/日志…）
- `migrations/` — 数据库结构升级脚本（改表结构只能加新文件，不能改旧的）
- `wrangler.toml` — 云上配置（名字/D1 绑定/静态托管方式）

## 二、我们是怎么"上传发布"的（部署流程）

```bash
cd outputs/light-todo-v3          # 进项目
npm run build                     # ① 把前端"打包"成给浏览器的最小文件 → dist/
cd worker && wrangler deploy      # ② 连同 dist/ 一起传到 Cloudflare
```
发布后全球约 1 分钟生效。改代码→build→deploy 就是一个完整发布循环。

## 三、数据与隐私（红线，勿破）
- 个人空间是**最私密**的：发给 AI 时只闲聊、绝不发任务明细
- 工作空间发 AI 的只是摘要（标题+日期+完成与否，最多 30 条），不含备注/备忘正文
- 任何新功能加"往外发数据"，先在这里确认是否越界

## 四、防坑铁律（踩过的坑，勿重蹈）
见桌面《轻待办-项目记录.md》§八（目前 11 条）。最痛的几条：
1. **PBKDF2 迭代上限 100k**（生产超了会 500）
2. 滚动列表要补祖先 `min-height:0` 链条，否则内容被裁"滑不动"
3. useMemo 依赖数组漏字段 = 静默用旧缓存（计数不更新）
4. React 受控表单自动化要原生 setter + 派发事件
5. 删/改云上数据前先想"这账号是不是有真实用户数据"——迁移用只读导出

## 六、凭据与安全处置（含"什么是 PAT"）
- **GitHub PAT** = 一串像密码的字符，让你不用每次输密码就能上传代码。
  我们项目仓库是**公开的**，读不需要凭据；PAT 只用来"上传/改代码"。
- 曾有一枚 PAT **明文写在项目的"上传地址"(git remote URL) 里**——任何能打开这台电脑的人/程序，一旦看到 `.git/config` 就能拿到它上传代码。
  已处理：把 remote 改回干净地址（token 从配置里移除）。说明见 [01-v38继续执行.md](./01-v38继续执行.md)。
- **处置建议**：去 GitHub → Settings → Developer settings → Personal access tokens → 撤销/轮换曾暴露的 token，改用更安全的 ssh 方式（需要时可以帮配）。新的 token 不要再粘贴进对话，用环境变量存。
- Cloudflare 也有几枚 API token 曾在对话出现 → 建议逐个去 Cloudflare 后台撤销/轮换。
- DeepSeek key 现在安全存在 Worker secret（`DEEPSEEK_API_KEY`），浏览器拿不到，OK。
