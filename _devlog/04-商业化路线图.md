# 轻待办 · 商业化路线图（2026-09-04）

> 目的：回答"从今天到能作为应用盈利，还差多少步"，给一张按阶段走的图。
> 目标（用户原话整理）：长久项目 / 至少收回成本 / 一年内想看到结果 / 网页+手机都要且数据多端同步 / 定位是"个人助手"。
> 定位一句话：**一个住在你设备里、帮你把随手记下的乱事变成"会自动理、自动盯、会为你高兴"的个人助手。**

---

## 0. 先说三件真话（决定路线图怎么画）

1. **个人做"收费 SaaS"，最难的往往不是做功能，是"收钱"本身**。国内正规接微信/支付宝收款基本要营业执照（个体户也行但得注册）；海外可用 Paddle/LemonSqueezy 这类"代收"服务（个人能开、收美元），但要面向海外用户+英文界面。→ 所以"收费"这一步要放到后期、且到时在岔路口再定走哪边，不要现在纠结。
2. **竞品多但都不"主动盯你"**。这是差异种子，但只是种子——要等 P1/P3 验证。
3. **成本其实很低**（Cloudflare 免费额度 + DeepSeek token 很便宜）。"收回成本"在钱上不难，**难的是"有没有人持续用"**。所以路线图里最重的一关是"留存验证"，不是"写代码"。

---

## 1. 全路线总览（5 个阶段，约一年）

| 阶段 | 名字 | 一句话目标 | 判断标准（过了才进下一关） |
|---|---|---|---|
| **P0** | 现状 | 网页 MVP 已上线 | ✅ 已完成（现在） |
| **P1** | 产品成形 | 你自己 + 3~5 个朋友**离不开它** | 你能自然说出"我每天靠它做 X" |
| **P2** | 手机可用 + 小范围开放 | 手机上也能记（PWA）；请少量陌生人内测 | 内测用户不是"看一眼就走" |
| **P3** | 验证卖点与留存（**生死关**） | 看第二天/下周还回不回来 | 开放 4 周，回访率达标 → 做 P4；不达标 → 回到 P1 或接受小而美 |
| **P4** | 收费 | 上订阅，覆盖成本 + 小赚 | 有人真的付费 |

**P0→P4 之间最该记住的**：P3 是 go/no-go 岔口。**别在没人持续用之前就做付费**——那只会白花收款/合规的力气。

---

## 2. 各阶段具体做什么

### P0 · 现状（已完成）
网页版已上线：E2EE 双空间、NLP 建任务、备忘录、桌宠轻宜、AI 对话、新手引导。✓

### P1 · 产品成形（目标：你离不开它）—— 建议 2~4 周
不做大而全，只做能"黏住你日常"的三件事（都来自前面聊的真痛点 + 竞品调研）：
1. **乱话变靠谱待办**：听懂"领导式口吻"（下周二前给个方案 → 有截止）；识别结果**当场抽成可点改小标签**。
2. **今日"轻宜建议"**：自动挑出"昨日没做完 + 快到期的 + 随手记没排的"，一键加入今天；空时轻宜给示范，不空屏。
3. **主动跟进 + 完成仪式**：轻宜隔段时间问你"那件还没打勾，办完了还是卡住了？"；你打勾它为你高兴 + 今日点亮。
> 做这个阶段的唯一目的：让**你自己**把它从"备忘录的替代品"变成"每天必开"。此阶段不推广、不收钱。

### P2 · 手机可用 + 小范围开放（目标：手机上也能用）—— 建议 2~4 周
- **PWA**（加到手机主屏，像 App 一样全屏用，数据天然多端同步）——比上架 App Store 快得多、零分成、免软著，是"一年内看到结果"最现实的手机方案。原生 App 留到真有付费用户后再谈。
- 请 3~5 个朋友/同事用起来，收集"哪一步他们卡住/不想用了"。

### P3 · 验证留存（目标：判断有没有戏）—— 建议 4 周
- 在少数渠道（如你朋友的圈、一个产品社区帖）**小范围公开**，不花钱投广告。
- 只盯一个数：**第二天回访率**（用户今天来了，明天还来吗）。≥某个值 → 说明黏住了人，进 P4；< 值 → 说明卖点没立住，回 P1 打磨，或接受"小而美自用"。
- 这一步决定要不要为它花钱花时间，**是整张路线图的开关**。

### P4 · 收费（目标：收回成本 + 小赚）—— 看 P3 结果再启动
- 轻量订阅制，免费层够用 + 付费层解锁（如 AI 对话额度、更多空间/回顾）。国内这类工具常见年费几十到一两百。
- **岔路口**（到时你拍板，现在不纠结）：国内收款（需营业执照/个体户，方便国内用户） vs 海外收款（Paddle/LemonSqueezy 收美元，个人可开，但要英文界面+海外用户） vs 暂不收（先靠打赏/爱发电，把"有人愿付"当验证）。
- 成本模型参考：当前几乎零固定成本；主要可变成本 = DeepSeek token。若你有几百个真实活跃用户、其中 2~5% 付费，即可覆盖成本且有富余。

## 3. 一年时间轴（粗略）

```
现在 ──10月── P1 产品成形（自用+朋友）
10月 ──11月── P2 手机 PWA + 小范围内测
11月 ──12月── P3 留存验证（go / no-go）
次年 1月 起 ── P4 收费尝试（若 P3 通过）
全年：每完成一步写进 _devlog，复盘
```

> 说明：这版是"务实一年"。如果 P3 没通过，不代表白做——它仍是你自己+朋友长期在用的个人助手，只是**别为它投入商业成本**。

## 4. 这一步你先做哪个？

路线图的价值是让你"心里有数、别乱加功能"。接下来最该做的不是铺功能，而是 **P1 的三件事**把它做成你离不开——要不要就从这里开始？还是你先消化这张图、有想调整的地方（比如某阶段顺序、或你其实更想先要哪一块）？
