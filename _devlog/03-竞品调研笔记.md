## 一句话总结论
**我们的问题不是功能少，是把已有功能"做得太安静"。** NLP 建任务、今日页、备忘录、桌宠、AI 对话其实都有了——缺的是把它们变成"**看得见的引导**"和"**让人想回来**的正反馈"。

---

## ① 卡片/碎片笔记（参考 flomo、memos 等）

**碎片笔记值得单独做的原因**：人最自然的记录是"打开就打字、发完即走"（微信"文件传输助手"被当记事本就是证据）。逼人先想标题/分类会杀死记录习惯。所以核心 = **先无脑收下，再靠回顾让它"不白记"**。

**别人共同的界面**：单列时间流（像朋友圈/私人微博）+ 顶部常驻输入框（无标题、无分类、回车即存、无"保存"按钮）+ `#标签`即点即过滤 + 不做文件夹树。

**最该抄的 4 招**：
1. **flomo「每日回顾」随机翻一张旧卡** —— 定时/主动"撞见过去的自己"，把"记了白记"变成最打动人的卖点。**我们可做：备忘录里加"随便翻一张"，或今日页/晚间由轻宜推一条旧备忘。**
2. **顶部常驻"发条随手记"输入框**（去标题去分类，回车落库归当日）——我们备忘录顶部已有一条，可再贴近"无压力"。
3. **memos 式"时间流 + 扁平标签即视图"** —— 别加多级文件夹。
4. **碎记默认归"今天"、日历能回溯** —— 正好复用我们已有的今日+日历。

**不适合**：Obsidian/Logseq 本地文件+双向链接（太重）、flomo 剪藏富媒体（滑向重收集）。

## ② AI 情绪陪伴（参考 Replika、Woebot、Pi、ESConv 研究等）

**让人"感到被理解"的共同手法（顺序纪律，比"会说"重要）**：
- 三阶段：**先问清 → 复述感受（镜映）→ 安慰 → 建议永远放最后**。直接给建议最破坏理解感。
- **精确点出情绪名 + 复述用户原词**（"听起来这件事让你很委屈"），比泛泛"我懂你"有效得多。
- 定位"站你这边、不评判"，不急于下结论。被理解感来自**被听见**，不是问题被解决。

**情绪分级做法**：两段式 —— 先判情绪+强度；轻度负向共情即可，中重度才认真接，**危机词（自杀/不想活/自残）必须前端本地关键词硬拦截**（不靠 AI 兜底），给热线话术且不再角色扮演。这是安全红线。

**最该抄的 4 招**：
1. **任务锚定**："要不要拆成一个小任务？做完我陪你划掉。" —— 别的产品没有的天然优势（我们是待办）。
2. **带记忆的次日关怀**："昨天那件烦心事，今天好些了吗？" —— 低成本"被记住"感（本地存情绪小标）。
3. 共情 prompt 写死纪律：不先共情+一次澄清不得给建议；不诊断/不评判/不说教；回复限短。
4. 危机词硬 gate + 热线。

**避免**：长时间角色扮演/亲密人设（成瘾+监管风险）、心理诊断（法律红线）、每次都长篇大论。

## ③ 桌面宠物（参考 dsh-pet-whale、Agentic-Desktop-Pet、Bongo Cat、Shimeji 等）

**让宠物"活"的关键 = 让它和"正在发生的事"同频 + 反应有不确定性**，而不是动画本身：
- 宠物状态跟随用户真实行为：新增/打勾任务→庆祝；专注→working；久不操作→打瞌睡；报错→发抖。
- 同一动作有**梯度反应**（连戳会升级：撒娇→躲→闹脾气），制造"它记得你"的错觉。
- 小破绽最出血肉感：悬空久了会问"还在吗"、甩晕后身体发软。

**让人"想养下去"的机制**：
1. **亲密度分档**：按互动数/完成任务攒亲密度，分档改台词，满档解锁专属彩蛋/动作 —— localStorage 即可。
2. **情感注入 AI**：把当前"情感值/亲密度档位"写进 DeepSeek 的 system prompt，让语气随陪伴时长变化，而非每轮一样。
3. **记忆式关心**：回复引用具体任务和时间（"你那件『买牛奶』还没打勾哦"）。
4. 低成本物理彩蛋多铺几种（连戳升级、贴边压扁、甩晕后遗症）——bloub 已支持变形，这些是"活人感"主力。

**最适合的范本**：**dsh-pet-whale**（同为 Web 端宠物 + 完整交互状态机）> Agentic-Desktop-Pet（情感+LLM）> ymhyyds/DesktopPet（任务关怀联动）。

**不适合**：系统托盘/开机自启/全局键鼠钩子（纯浏览器没权限）、Desktop Goose 式满屏恶作剧。

## ④ 任务管理 + 新手引导（参考滴答清单、Todoist、Things、微软、flomo）

**最被称道的体验点**：
- **一句话建任务**：NLP 识别到的日期/优先级/标签**实时高亮并从标题剥离成可点的字段**（不是建完才知道认没认对）。
- **完成仪式**：清脆"叮"声 + 成就勋章 + 完成即鼓励 —— 把"完成"变成可累积的回报。
- **"今日"手动挑选式**（微软）：今日 = 亲手挑 ≤3 项，配"建议"灯泡给候选（昨日未完成/临近到期）—— 让"今日"有掌控感。
- **极低记录摩擦**：像只给自己看的微博。

**新手引导通用原则（最高杠杆 = 空状态）**：
- 空状态 = 一句用途说明 + 一个"创建第一个 X"按钮 + 做成后什么样子的示意；**别放要删除的示例数据**。
- 开场用"金句 + 一句话示范"（滴答示范写『晚上8点阅读60分钟』而非『阅读』，教的是"具体"）。
- 3 步内，做一遍胜过看一遍。

**最该抄的 5 招**：
1. **NLP 高亮 + 剥离成 chips**（Todoist/Vikunja Quick Add Magic）——识别到的"明天 16:00"从输入里抽出来变成可点改的小标签。E2EE 本就本地解析，正合适。
2. **空"今日"页做成首次引导**：一句用途 + 建任务按钮 + 一句话示范，借桌宠承接（我们的新手引导可更"空状态驱动"）。
3. **完成仪式**：完成音效 + 今日成就点亮格（flomo 贡献墙式）+ 轻宜立刻说一句鼓励。
4. **今日页"建议栏"**（微软小灯泡）：昨日未完成 + 临近到期 + 随手记候选，一键入今日。
5. **晚间回顾**：睡前轻宜推"明天 3 项建议"。

**不适合**：团队协作/看板评论、AI 全自动排时间块（Motion/Amie 学习陡+绑云端）、GTD 多层项目。

## 交叉点：几条线都指向同一件事
① 要回顾、② 要带记忆的问候、④ 要晚间/随机回顾 —— **"轻宜主动、有记忆地关心你"是这次调研最大的共同信号**，也是我们（有宠物 + 有 AI + 有脱敏记忆）相对纯 todo 的差异化。已具备底座，缺的是"常驻的回顾/问候节奏"。

## 建议的下一批功能（按"改动小见效快 → 大工程"排）

**A 档（快，纯前端 + 复用现有）**
1. 完成仪式：打勾音效 + 今日完成数点亮/小彩带 + 轻宜即时一句鼓励（现在打勾只有动画，静悄悄的）
2. 轻宜"带记忆"：把最近完成/未完成任务 + 情绪小标，作为对话与主动搭话素材（"昨天那条打勾了没"）
3. 空状态改造：今日/备忘录空时，给"一句话用途 + 建第一条按钮 + 示范"，借轻宜嘴说

**B 档（中）**
4. flomo 式回顾：备忘录加"随便翻一张旧卡" + 晚间轻宜推一条今天的随手记
5. 亲密度：按互动/完成任务攒"亲密度"，分档改台词 + 升级轻宜自己报喜
6. NLP 高亮 chips：输入"明天下午4点开会"，识别出的时间当场高亮抽成可点改小标签

**C 档（大 / 需再想）**
7. 今日"建议栏"（昨日未完成+临近到期+随手记，一键加入今日）
8. 宠物"任务状态机"（跟随你真实动作庆祝/打瞌睡）
9. 情绪分级 + 危机词硬 gate（安全功能，值得单独立项）
